# API Documentation
## Smart Invoice Manager

Base URL: `http://localhost:8000/api`

> Live interactive docs are auto-generated by FastAPI at `/docs` (Swagger) and `/redoc` once the backend is running. This file is a quick-reference summary.

> All endpoints below except `/auth/*` require `Authorization: Bearer <token>` (obtained from login/registration).

---

### 0. Auth Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | `/auth/register` | Submit name, phone, password → creates the account and returns a JWT |
| POST | `/auth/login` | Submit phone + password → returns a JWT |
| GET | `/auth/me` | Returns the current authenticated user (requires bearer token) |

---

### 1. Vendor Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | `/vendors` | Create a vendor |
| GET | `/vendors` | List all vendors |
| GET | `/vendors/{id}` | Get vendor details |
| PUT | `/vendors/{id}` | Update vendor |

---

### 2. Invoice Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | `/invoices` | Create invoice (with line items) — validates BR-1, computes total (BR-2) |
| GET | `/invoices` | List invoices — supports query params below |
| GET | `/invoices/{id}` | Get full invoice details |
| PUT | `/invoices/{id}` | Update invoice (fields + line items) |
| PATCH | `/invoices/{id}/status` | Update payment status / amount paid |
| DELETE | `/invoices/{id}` | Delete invoice |

**Query params for `GET /invoices`:**

| Param | Type | Description |
|---|---|---|
| `vendor_id` | int | Filter by vendor |
| `status` | string | `unpaid` \| `partially_paid` \| `paid` |
| `overdue` | bool | Only overdue invoices |
| `from_date` / `to_date` | date | Filter by invoice date range |
| `search` | string | Search invoice number / vendor name |

---

### 3. Dashboard Endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/dashboard/summary` | Total outstanding, overdue amount/count, status breakdown |
| GET | `/dashboard/spend-by-vendor` | Aggregated totals per vendor |
| GET | `/dashboard/recent-invoices` | Most recently created/updated invoices |

---

### 4. AI Extraction Endpoints

| Method | Endpoint | Description |
|---|---|---|
| POST | `/ai/extract` | Accepts text, image, or PDF; returns extracted structured invoice data (not saved) |

**Request:** multipart form (`file`) or JSON (`text`)
**Response:** JSON matching the Invoice creation schema (vendor name, invoice number, dates, tax, total, line items) for pre-filling the review form.

---

### 5. Common Response Format

**Success:**
```json
{
  "data": { ... },
  "error": null
}
```

**Validation Error (e.g., duplicate invoice number):**
```json
{
  "data": null,
  "error": {
    "code": "DUPLICATE_INVOICE_NUMBER",
    "message": "Invoice number INV-1001 already exists for this vendor"
  }
}
```
